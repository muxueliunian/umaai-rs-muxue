> 只测量，未改任何已跟踪源码。时间为 UTC+9（JST）。

## 1. 对拍对象与偏差说明

| | 提交 | 说明 |
|---|---|---|
| 旧 | `fefb87a` | R8 采集提交（`git worktree add ../old fefb87a`） |
| 新 | `17f09fa` | `origin/master`，含 `0bcb79d`，共比旧版多 23 个提交 |

与任务书的出入（均已处理，无需再决定）：

1. **本地 `master`/HEAD 仍停在 `fefb87a`**，需 `git fetch` 后取 `origin/master`（17f09fa）作为“新”。
2. **新旧差异不止 `0bcb79d`**：23 个提交里影响模拟器的只有 `local_ramen_trainer.rs`、`action.rs`、`state.rs`（观测字段）、`config.rs`、`gamedata/umaDB.json` 等；结论见 §5，其余 22 个提交在手写路径上无影响。
3. **`--plans-file` 与 `--plan-stride` 在两边都互斥**（源码 `ensure!(args.plan_stride == 1, ...)`）。B 组改用预抽样清单 `scripts/holdout_stride16.json`：把 `r8_gen2_0920/holdout.json` 的 250 个计划每 16 个取 1 个（→16 个），**保留原始 plan 下标**，逐计划种子 `seed + plan_index*1000003` 不变。
4. **默认工具链 rustc 1.94.1 无法编译**：`Cargo.lock` 里 `kstring 2.0.4` 要求 rustc ≥1.96。为不改 `Cargo.lock`，两边都用 `RUSTUP_TOOLCHAIN=1.96.0`。
5. 环境无 `/usr/bin/time`，用 `scripts/timed.py`（wall、子进程最大 RSS、整机 MemAvailable 最低值）代替。
6. **容器在 06:49~07:06 重启一次**，B 新版被打断（已完成 7/16 局），用 `--resume` 从日志续跑；结果与不中断等价（逐局落盘、种子确定）。

## 5. 结论

**A 组（手写，1000 局配对，效力充足）**
- score 均差 **−163**（95% CI [−263, −64]，新胜/平/负 383/159/458），显著，但仅约 −0.25%（旧均分 66500 → 新 66337）。逐局差的 sd ≈ 1607，属于小幅、方向一致的系统性下移。
- 五维里显著的是 guts（−9.7）、speed（−4.6），其余在噪声内；技能 PT −3.7、剧本 PT +24 均不显著。差值主要是“属性小幅下降”，没有单一维度大幅崩坏。
- 按构成：四种构成方向一致（−106 ~ −273），2速1力1根1智1友、2速1耐1力1智1友的 CI 不含 0，其余含 0（样本少）。
- **来源已定位：全部来自友人出行跨年配额 [0,2,5]→[0,3,5]。** 新二进制加 `--variant fcap025`（把配额还原为旧值）后，1000 局所有公共列与旧提交**逐列完全一致**（均差 0.0，1000/1000 平）。也就是另外 22 个提交（含 gamedata/umaDB 更新）在手写路径上零影响。
- **“5 次必须走完”门限在采集口径里没有生效**：`ramen_space_bench`（与其头部注释所述的 `ramen_teacher_collect` 口径一致）不读 `friend_complete_required`，`LocalRamenConfig` 默认为 false，只有 `bench_base` 与 `umaai` 才接线。用 `--variant freq` 显式打开后：配额 [0,3,5] 下再变 −9.7（噪声内），配额 [0,2,5] 下 −15.5 [−55, +24]（噪声内）。门限本身对手写分数影响很小。
- 新版出行走完率 99.0%（990/1000 局出行 ≥5 次；逐年 y1=0、y2≈2.8、y3≈2.2）。旧版 CSV 无 `friend_out_*` 列，不改源码无法给出旧版走完率。

**B 组（教师 search，仅 16 局，效力不足）**
- score 均差 +213，95% CI [−499, +924]，新胜 9/新负 7，**不显著**；stamina +79 显著属多重比较下的偶然，不作结论。逐局差 sd ≈ 1336，n=16 时半宽约 ±710，**无法分辨 A 组量级（−163）的偏移**，只能说没有发现大幅漂移。
- 世界配对：A、B 均为 (plan_index, run_idx) 与逐局种子 100% 一致；A 组有 159 局分数与全部公共列完全相同（配额不触发分歧的局），证明两边世界配上了。B 组无完全相同的局是预期的（搜索会放大任何微小的决策差异）。

**对“能否与 53 万旧语料直接混训”的含义（仅陈述测量事实）**
- 手写 roll-in / rollout 的整局分布相对旧提交存在可测的小幅系统偏移（约 −163 分，−0.25%），来源单一（配额）；教师整局分数在本次样本量下无法检出偏移。
- 本实验测的是**整局分数**，不是每个根上“候选间相对分数”的标签；标签层面的漂移需要另做根级别对拍（如 `ramen_root_bench`），本次未做。
- 采集路径不带“5 次走完”门限，所以该门限不构成新旧语料的差异来源。
