# 口径与术语速查（metrics_glossary）

> digest.json 各字段的确切含义。与 `.trae/documents/replay_review.md` 同源；
> bin 侧实现以 `crates/umaai_review` 为准。

## 运气分体系

| 术语 | 含义 |
|---|---|
| `T(n)` / `t_n_display` | 第 n 个决策点的「局面期望终局分」估计（display 口径 = raw + (78 − turn) × mcts_turn_bonus） |
| `t_n_raw` | 反推的 raw 值（bonus 剥离后） |
| `turn_delta` | T(n+1) − T(n)，是**局面期望变化**，不等于本回合属性增量 |
| 回合合计 Δ | 同回合多段（RamenSelect / Train / RegionSelect）Δ 之和——**基本观察单位**；吃面段正 + 训练段继续正 = 好局面 |
| `total_luck` / `total_luck_end` | 累计运气分（终局值）；**支援卡事件进度未统计 → 系统性略低于实际运气**；`< -2000`（≈方差量级）仍可判「这局运气差」 |
| `flagged_turns` | 伪波动标记（年界 [24,48,72] 前 2 至后 1 回合 / 继承 [30,54] / RMJ playing_state 46·48 自动检测 / **开局 t2-3 第 1 年地区选择**——地区选择带来的期望跳变也是程序性）。归因时降级或跳过；**turn 72 双属性**：既标记也算进超级拉面统计（份量实打实） |

## 阶段与决策

| 术语 | 含义 |
|---|---|
| 决策点快照 | **行动前**局面；行动结果体现在下一个 turn 更大的快照 |
| 锚点 | 每回合最后一条 `decision_kind=train` 的 calc 行（Train 阶段是最终执行；不吃面路径的 RamenSelect 行即最终项） |
| 同回合 seq 递增 | 阶段推进，**不是**行动结果 |
| `chain_len` | 同 file 连续行数（链式决策长度；在线留空，bin 推断回填） |
| skip 行 | stage=Begin 的不派发快照（event / RMJ / 数据不全 / 超拉丢包），见 `coverage.skip.by_reason` |
| `raceHistory` | 只记**跑赢**的比赛；输掉的比赛需用 schedule 兜底判「比赛」 |

## 执行推断（execution）

| 项 | 口径 |
|---|---|
| 比赛判定 | raceHistory +1（跑赢）**或锚点回合 ∈ 必赛回合 ∪ URA 73/75/77** |
| 训练判定 | **分年分段阈值**：第 1 年用训练基础值表最低主维（等级 1 裸值，实测 7）；第 2 年起固定 12（事件增益通常 < 12）；另需**非大回复**（体力 < +25，防「休息+事件属性」误判）；**智训练不耗体力**（表值 +5 叠事件最多 +20） |
| 休息判定 | 体力 ≥ +25（表值休息 +30~+70；容忍事件小额属性） |
| 继承窗口 | 锚点 29/53 的窗口含继承落地 → 实际动作标注「继承混合」、不参与一致率（无法从数据剥离） |
| 一致率 | game6234 实测 89.3%（75 可比 / 8 偏离）；AIRedirector 局仅作校验 |

## 剧本机制常量

| 常量 | 值 |
|---|---|
| 年份边界 | [24, 48, 72] |
| 继承回合 | [30, 54]（与年界错开 6 回合的独立事件） |
| 超级拉面期 | turn ≥ 72；开局自动加体力与心情（干劲），掉状态有兜底，恢复建议不必要求 72 前手动补 |
| 继承参考值 | `Σ(extra_count[0..5]) + 126`（game_config `[config_override]`，只比五维不含 PT） |

## 分身彩圈（clones）

| 术语 | 含义 |
|---|---|
| 新增分身 | 吃面前出现 ≤1 位 → 吃面后 ≥2 位（卡 × 回合事件） |
| 分身落位 | 末快照位置 − 本体位；absent 卡 = 全部末位 |
| **彩圈** | 分身落位 == cardType（**本体占的得意位不算**；任意位口径的 52% 命中率大部分是本体占位假象，实测真实落位仅 2/31；分身主要价值是提高训练效果，玩家已知，叙事不解释） |
| 彩圈来源 | `luck` = 吃面前本体在场（随机有效增加 → 好运气）；`strategy` = 本体缺席被规则带入（规则有效增加 → 好策略） |
| 彩圈吃到 | **A 类**：`a_per_turn` 明细的 `used` 字段（当回合实际训练命中彩圈位 → 吃到收益；未考虑分身存续期的后续训练）。**B 类**：机制保证落位，没吃到不算亏 |
| A / B 类 | A = turn<72 地区分身（判据待定义，纯观测）；B = turn≥72 超拉分身（**只统计训练卡**——友人 cardType=5 无得意位；机制保证 100% 落得意位的旧说法基于任意位口径） |

## 评分与赛程

| 项 | 口径 |
|---|---|
| `final_score` | `Uma::calc_score` 同源（五维加权 + PT 折算），**仅供参考**：略低于小黑板实际分数、未计入「努力家」等新状态（快照 skillScore 恒 0） |
| `rank` | 与 rank.csv 同表换算 |
| 五维显示值 | digest `timeline.five_status_display`（bin 已按 (real − 1200) / 2 + 1200 换算，real > 1200 时）；叙事报显示值，评分与运气分不受此换算影响 |
| 必赛 / 自选 | `schedule.mandatory_turns`（umaDB races）；自选 = raceHistory − 必赛（区间内）；URA 73/75/77 是剧本固定赛不算自选 |
| 不可做 | 评价「该选哪场比赛」（比赛池不在 gamedata） |

## 已知偏差（读运气分必看）

1. RMJ 结算时机可能与实际数据不符 → 运气虚高（局部，年界附近，flagged 已标）
2. 支援卡连续事件进度未统计 → **整条曲线**被系统性压低；且 AI 会因此「掉心情后不主动恢复」（正是「心情掉落未恢复」检查项的成因）

## 归因口径（用户拍板）

- **目标赛未跑赢、超拉期连亏、掉干劲本身 = 运气，不是操作**：输赛是随机结果，
  掉干劲由输赛带来，超拉期估值走低是随机落地差；叙事归运气，不当坏手法表述
- 「掉干劲后未主动恢复」是偏差②导致的决策倾向，作观察项与改进方向
- 比赛叙事口径：全胜是基本操作不提战绩，输赛才展开（用户拍板）
