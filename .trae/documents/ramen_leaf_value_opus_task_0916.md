## 3. 固定模型、目标与 rf 的处理

模型：

```text
saved_models/arms/ens_NT4096_AllHistory_g123.onnx
saved_models/arms/ens_NT4096_AllHistory_g123.onnx.json
target/arm_NT4096_AllHistory_seed1/step_030000.pt
target/arm_NT4096_AllHistory_seed2/step_030000.pt
target/arm_NT4096_AllHistory_seed3/step_030000.pt
```

从旁车 `ensemble_of` 核对成员顺序，核对各 checkpoint 和旁车归一化。不要继续加载旧 G2mix 成员，仅改 ONNX 文件名却不改 GPU checkpoints 会构成错误实验。

冻结：FP32、TF32 关闭、三成员、固定 B512、policy-cache 开、sidecar-graph 开、自适应 batch 关。新模型需重做小批 CPU/ONNX/GPU 的 shape/有限性/数值/动作核对；旧 G2mix 的零分歧不能直接当 AllHistory 的证据。

仅截断模式的根目标：`Q(a) = mean_j(Z[a,j])`，每候选同样 n、完整候选、CRN、无 UCB。终局 `Z` 是正常 `calc_score/search_score.score`；非终局 `Z` 是叶节点反归一化的 `value[0]`。同一截断模式内，提前终局和叶预测统一按该均值目标聚合，不能把两类样本分开使用不同权重。完整续跑模式不受此定义影响，继续使用原 rf 目标。

- 截断模式要求聚合实际 rf=0；若最小实现复用生产 `ActionResult::mean/weighted_mean(0)`，完全允许。普通 full 模式保留原 `radical_factor_max` 及随回合的计算。日志同时报告配置值与实际聚合目标，不把截断模式的0写回公共配置或污染后续full调用。
- 不全仓删除 rf、历史标签 value[2]、模型输出或其他模式的配置。旧路径默认保持不变。
- 不把 score_pt、PT 偏好、奖励塑形、加回当前分数、折扣因子混入目标。显式核实 root 最终 argmax 只依赖普通 score 均值。
- 主参考是原 full-rf 搜索。完整续跑的 mean 推荐仅从同一份 raw 离线计算，不另跑一套、不改full实际选优；用于区分“rf→mean的目标变化”与“mean→leaf-mean的估值变化”。

value 的重要边界：标签是“其余列挑候选、留出列由教师续跑估值”的 cross-fit 结果，不是严格的 `V^AllHistory`。早期教师/规则也混在 AllHistory 语料中。policy 闭环更强不等于 value 已校准。value[1] 是目标分布标准差，不是模型置信度；value[2] 本轮不用，不拟合正态、不从三数伪造终局分布。

## 4. 截断语义：实现之前写清楚并冻结

支持显式 `full / H4 / H8`，默认 full。参数名称可贴合现有 CLI，但必须在 README/预登记写明实际名称。不得借现有 `max_depth` 名字静默改变其他搜索模式。

### 深度定义

保存应用根动作前的 `root_turn`。目标回合 `root_turn + H`；在达到该回合后遇到的第一个**合法、安全的决策前边界**做 leaf。H 表示跨越 H 个 turn 边界，不是 H 次选动作/推理；根回合可能只推进剩余部分，不声称完整执行了 H 个新回合。记录实际 leaf_turn/stage/turn_delta 及延期原因。

### 边界要求

1. 根动作已执行且只执行一次。
2. 正常 `next/run_stage` 推进，不能跳过事件、RMJ、结算或待落地的吃面效果。终局优先完成 `on_simulation_end`，取真实终局评分，且只能结算一次。
3. 仅在特征编码器与训练样本含义一致的决策前边界估值。候选为空、非决策阶段、Settlement 不估值。
4. 第一版不在 SpecialSelect 截断：训练 stage1 为空，不能因为其特征和 RamenSelect 相同就假定 value 语义相同。继续正常推进到安全阶段并记录延期。
5. RamenSelect/Train/RegionSelect/SuperRamenSelect 是否安全，必须核对编码与 pending/combined 决策状态；不能猜。不能为了达到深度清空 pending 或篡改 stage。
6. leaf 条件检查独立于 policy 的 `NeedsInference`：单候选/守门导致 policy 不推理，不等于无需 value。是否在这些状态估值须依照安全边界，不得因 prepare 返回 Resolved 就把截断静默推后很多回合。
7. 实现有推进上限/异常保护。边界无法证明安全时，停止该实现并报告，不猜一个 turn/stage。

### 请求与输出

- 显式区分请求用途（PolicyDecision / LeafValue）与结果类型（Terminal / Leaf），避免 value 响应被当成一次动作执行。
- leaf 返回后不调用 `run_decision`，不消耗动作、不再推进轨迹；释放局面。
- 叶预测保留浮点，聚合建议 f64；不取整、不裁成整数直方图，不因超出经验区间而静默 clip。shape/非有限/反归一化非有限须立即失败。
- 侧车的 value 已“各成员反归一化→实际分数平均→按成员0重归一化”；Rust 按匹配的旁车尺度解码一次。不要二次加中心，也不要直接平均不同尺度的 normalized value。
- 现有 policy cache 不含 value。本轮不扩展 leaf cache，不拿缓存 policy/旧状态 value 冒充叶输出。固定 B512 图静态输出必须在下次 replay 前安全取走。
- 统计 policy 请求、leaf 请求、terminal 条数分别计数；total_requests 应能核对两类请求之和。

#### 独立评估列（防止把自己选出的最大值当无偏真值）

- 完整参考为每候选512列，前256列是 selection bank，后256列是独立 audit bank；每个 bank 内所有候选共享对应种子。
- full-rf与离线full-mean推荐都只用前256列选；H4/H8各自只用同一前256列前缀做leaf并选动作。
- 四种推荐动作的价值都在后256列真实终局结果上以普通均值评估：分别报告 `audit_mean(full-rf选择) - audit_mean(leaf选择)` 与 `audit_mean(full-mean选择) - audit_mean(leaf选择)`；再报full-rf/full-mean之差。允许差为负，不能裁0。该audit衡量真实期望分，不声称是对风险目标本身的估计。
- 同时报告前256列下的观察 regret/top1，但明确它有选择偏差，不是金标准。audit 中重新取 max 的 regret 也有偏，不能冒充独立真值。
- 该完整参考续跑仍是 AllHistory，不是手写；audit 只用于评价，不参与挑候选或修改深度。
- 按列CRN计算已固定动作对的差值SE，报告参考自身噪声；不要用候选各自绝对方差之和代替配对方差。24根的小试点不承诺统计定论。

#### 必报指标

- 每候选真实终局均值、叶均值、偏差；每根去掉共同偏移后的候选相对误差。
- 三个运行臂及离线full-mean的选中项、候选差值误差、audit配对损失、最差根及前若干大损失根；包含全部根，不只列成功案例。
- 按阶段、早/中/晚、地区年份分层；value绝对MAE与候选排序分开。
- 截断终止/真实终局数量、叶回合和阶段、实际推进深度、延期次数、policy/leaf请求、缓存命中、波次、格位/填充率、峰值内存、错误数。
- 固定 n 速度/误差曲线，不额外扫n、深度、混合比例。

#### 计时

诊断完整512列的耗时不能除以2冒充full256实测。另选预先指定的3个代表根（早期吃面、中期Train、Y3地区），对full256/H4/H8做3次平衡顺序交错重测。每臂同机同段运行，关闭重型trace，记录预热外墙钟与侧车往返；冷启动单列。

不同时跑多个性能臂。若同臂重复明显漂移，报告中位数/范围、环境干扰，不拿最快/最慢之比当稳定收益。Graph固定B512，不趁此优化传输或批大小。

### T4：一对整局接线冒烟（有条件执行，不是棋力验收）

条件：T2通过；T3全根结果齐全、无非有限/身份错位/规则疑点；无须跨剧本接口重构；预算足够。T3有负面效果不藏，若已显示明显不可用可以直接负结果结案，不为了跑完任务浪费时间。

固定比较原有 full-rf 与 H8-mean，不看T3结果临时改成H4/H16。使用预登记的同一计划/新世界，根搜索 n=256、all搜索阶段、完整地区候选；续跑是无搜索AllHistory，不做嵌套搜索。纯NN动作/必要守门与搜索装配关系两臂一致，记录实际装配。这一对同时包含目标变化与截断变化，不声称隔离了截断的单独效果。

一局两臂的决策及终局本来就可能不同，不能再要求“逐步零分歧”作为leaf正确性门槛。必须比较相同起始状态/模型/搜索预算/种子，审计每次root的候选计数、leaf实际生效、无静默fallback；另有T2的无截断等价测试。

报告分数、失败状态、耗时、请求与leaf数；一对局只证明可以闭环执行，不证明强弱或稳定提速。若不可运行，明确未做原因，不自行扩大工作范围。

## 7. 解读与停止规则

本轮没有用户批准的“可以损失多少分”的部署门槛，不得自行把50分/1%或某个速度比当生产验收标准。

- 准确但没省时间：说明截断深度、请求开销和批利用率，停止，不自动叠加新优化。
- 明显更快但排序差：报告候选差值失真与具体阶段，结论可以是现有value不适用。增大n不能修复系统偏差。
- 有潜力：提议下一轮冻结一个深度，跑有足够组合/世界的配对效果面板；同时给固定n与固定墙钟的不同问题，不能混为同预算。
- 不能通过本轮证明旧rf策略已被均值策略取代；也不能证明NN搜索强于手写搜索，后者仍需独立对照。
- 不因A−G2mix纯策略+245分就承诺NN搜索或蒸馏学生提升。
