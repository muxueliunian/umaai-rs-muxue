本轮教师仍是 CPU 手写终局 rollout，NN 仅用于 roll-in，不能临时换成 GPU/NN 教师。

## 1. 取得代码与模型

在已有工作区根目录检查 Git 状态。工作树有修改或当前分支不适合快进时，先报告，不做 reset、删除或覆盖。

```bash
git status --short
git branch --show-current
git pull --ff-only origin master
git rev-parse HEAD
```

HEAD 必须等于本次交接给出的完整提交号。已提交的 `scripts/collect/r10_*_1004/` 是正式清单，
云端无需再运行 `prepare_r10_1004.py`，尤其不能重排 plans 或换号段后续跑。

模型参考单独下载到新目录，保留云端现有模型。以下目录若已存在，先检查，不用 `--clobber`：

```bash
gh release download models-r8a-0920 --repo muxueliunian/umaai-rs-muxue \
  --pattern 'ens_R8A_g123.onnx*' --dir target/r10_release_assets_1004
```

本地已将这两份 Release 文件与既有模型逐字节比对一致。云端预检也逐字节比对，不以大小、时间戳或摘要代替。

## 3. Release 构建与小冒烟

云端 Linux 内存有限时可按单次命令覆盖链接优化，保持 Release，不写系统配置：

```bash
cargo --config 'profile.release.lto="thin"' --config 'profile.release.debug=false' \
  build --release --locked -j 2 -p umasim --features onnx \
  --bin ramen_teacher_collect --bin ramen_export_npy
```

先在独立冒烟目录、冒烟号段验证四个新空间各至少一份 BIN 与 raw 导出；示例先验最容易暴露新赛程问题的 newuma：

```bash
target/release/ramen_teacher_collect --space-version gen4_newuma_v1 \
  --start 7900000000 --count 8 --search-n 16 --shard-size 2 \
  --output-dir training_data/r10_smoke_1004/newuma \
  --rollin nn --model saved_models/arms/ens_R8A_g123.onnx --model-id ens_R8A_g123 \
  --max-seconds 180
target/release/ramen_export_npy --space-version gen4_newuma_v1 \
  --input training_data/r10_smoke_1004/newuma --output-dir training_data/r10_smoke_1004/newuma_raw --raw
```

其余三个空间分别用起点 `7910000000` / `7920000000` / `7930000000` 和独立目录，
不要复用示例目录或已占用序号。冒烟的低搜索预算只用于通路检查，不能混进正式 1024 数据或用于承诺正式吞吐。
新马批还需单独覆盖气槽：本冻结计划中起点 `7940005328` 命中 `101803`，可用新目录、`--count 2`
和 `--region-quota-permille 0,1000` 验证第三年地区的 120 候选续跑；不要把这份冒烟并入正式数据。
采集 manifest 必须显示对应新空间、`friend_complete_required=true`、正确模型身份；正式前再以小批 1024 测量实际成本。

## 4. 正式启动

线程数依据实例实际 CPU 配额设置。下面的 `THREADS` 为本 shell 的普通变量；不创建新机器、不改全局环境配置。
每批使用已冻结的 1024 预算和独立目录，失败立即停止。恢复时使用同一命令、同一线程数与同一提交。

```bash
set -e
THREADS=<实例实际CPU配额对应线程数>
for entry in brian:6000 admire:6000 dualwis:3000 newuma:12000 control:3000; do
  batch=${entry%:*}
  count=${entry#*:}
  python scripts/collect/run_formal_collect.py \
    --plan "scripts/collect/r10_${batch}_1004" \
    --expect-search-n 1024 --expect-target-valid "$count" \
    --exe target/release/ramen_teacher_collect --export-exe target/release/ramen_export_npy \
    --output "training_data/r10_${batch}_1004" \
    --asset-reference target/r10_asset_reference_1004 --threads "$THREADS"
done
```

沿用已有保活和增量备份方式，每批导出 raw 后再认定完成。不要删除旧批、失败导出目录或孤立分片；遇到恢复拒绝先核对原因。
