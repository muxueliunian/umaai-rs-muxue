# R11：新规则 gen2_v1 每候选 256，按 22 小时截止分轮采集

本轮在合入上游超级拉面效果修正（2ec6b49）后的新规则下，重新采集 gen2_v1 空间的教师数据。
只做教师采集、raw 导出、验收与备份，不训练。旧 R6–R10 的 rollout 不能用重打标签的方式转换成新规则数据。

## 冻结口径

- 规则：本次发布提交（含 2ec6b49 超级拉面修正与选项训练上限）。与 R9（53d2d86）、R10（f228236）评分规则都不同，分目录保存，不与旧批混称同口径。
- 空间：gen2_v1（8 马娘 × 16 卡，4 构成，4288 组合），不购买开局增益。
- roll-in：`ens_R8A_g123`（Release `models-r8a-0920`，成员 `R8A_seed1/2/3` 各 60000 步，logit 平均集成）。
- 教师：手写终局 rollout，**每候选 256**、uniform（`use_ucb=false`，`search_group_size` 只在 UCB 下生效）、rf 1.4、地区 All、ε 0.15、gen1 继承、友人完成门限开启；保存全部 `[候选, 256]` 有序原始分数。
- 排除：只排除闭环留出 250（与 R6–R10 同一批），实际参与采集 4038 个组合，覆盖与 R6–R10 相同。各历史清单与本空间的交集见 `r11_gen2n256_1005/exclusion_report.json`。
- 分轮：每轮 10000 有效根（R9 gen2 四万根配额 ÷ 4：构成 9:9:13:9，层 general:Y1:Y2:Y3 ≈ 87.7:1.8:5.2:5.2），最多 40 轮。
  每轮内先 Y3、再 Y2、Y1、general。**到达截止时，已完成的整轮都是分层均衡的**；未满的那个任务把已写完整分片另行导出并标为 partial。
- 截止：清单声明 79200 秒（22 小时），在 24 小时预算里留出构建、冒烟和打包。根数不预先保证，按实际截止结果交付。
- 号段：正式独占 `[8000000000,12000000000)`；云端冒烟 `[12010000000,12020000000)`；本机冒烟 `[12000000000,12010000000)`（已用，不入数据）。

## 4. 正式启动

```bash
THREADS=<实例实际CPU配额对应线程数>
nohup python3 scripts/collect/run_formal_collect.py --plan scripts/collect/r11_gen2n256_1005 \
  --expect-search-n 256 --expect-target-valid 400000 \
  --exe target/release/ramen_teacher_collect --export-exe target/release/ramen_export_npy \
  --output training_data/r11_gen2n256_1005 \
  --asset-reference target/r11_asset_reference_1005 --threads "$THREADS" \
  --stop-file training_data/r11_gen2n256_1005.STOP \
  >> training_data/r11_gen2n256_1005_driver.log 2>&1 &
```

（用现有 tmux/nohup 保活。`--expect-target-valid 400000` 是 40 轮上限，不是承诺根数。）

- **安全停止**：`touch training_data/r11_gen2n256_1005.STOP`。驱动在当前根写完后收尾，退出码 3。
- **续跑**：先删掉停止文件，再用**同一条命令**（同提交、同线程数、同输出目录）。截止时间沿用首次启动时的时间，不会重置。
- **硬中断**（如断电）：完整分片保留，同命令续跑。若恰好断在分片写完、manifest 未写之间，续跑会因孤立分片拒绝，此时人工核对后报告，不要删除后盲跑。
- 程序错误（退出码 1）、配方或资产不符一律停下报告。正常到达截止时驱动打印「采集窗口结束：完整 N 轮……」，退出码 0。

## 5. 验收

```bash
python3 scripts/collect/verify_round_collect.py --plan scripts/collect/r11_gen2n256_1005 \
  --output training_data/r11_gen2n256_1005
```

逐字段核对：每份导出的提交、`search_n`/列宽 256、候选指针无缺行、每候选 256 列全部有效且有限、index 全局不重复且属于该任务的冻结清单、组合字段与计划原文一致且不落在留出/排除内、采集 manifest 与导出根数一致。
报告写到 `training_data/r11_gen2n256_1005/acceptance.json`（各轮、层、构成、阶段的根数）；有任何错误则退出码 1。
